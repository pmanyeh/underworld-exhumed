# UW1 繁體中文文體規範 — 權威詞彙稿

## 語言

繁體中文，台灣用語；忠於原作語意、情境及人物差異。正式術語依 authority，不由文體規範另起別名。

## 標點

- 中文句內使用「，」「。」「：」「；」「？」「！」；不混用半形替代標點。
- 一般引號使用「」；引號內再引用使用『』。
- 書籍、文獻與作品標題使用《》；一般地點或人物名稱不套書名號。
- 刪節號用「……」，不使用連續英文句點表示中文停頓。
- 中文標點前後不任意插入空格。保留資料格式需要的空白、跳脫、換行及控制碼，不以排版偏好改動。
- 原始英文 token、key 或數值語法保持原格式。符號本身是遊戲輸入或規則時，另做用途核對。

## 名稱

正式台灣手冊的核准人名、地名、種族、頭銜與奇幻專名優先沿用；保存來源頁。
本輪採使用者指定 Translation_Guide.md 的明列譯名，保存來源行號；沒有把指南自述當作原圖已核准。
無核准定名時：依 GLOSSARY.tsv 的 project-selected 暫定選詞保持一致；明確未解的外語名稱保留英文。暫定選詞不是官方定譯。
可音譯不可意譯的人名、可意譯的職稱、具有劇情雙關的地名，分別記理由，不用單一規則硬套。
同名不同角色或物件要另辨身份；敬稱／頭銜與本名分開記錄，避免把頭銜誤當名字。
使用者已明確裁定的例外以 USER-DECISIONS.tsv 為準：安卡十字騎士團（Crux Ansata 的騎士團各種英文形式）；Sir Almric／Baron Almric 均譯阿姆瑞克男爵；Lady Arriana／Arial 暫視為不同人物，不互設英文別名。
指南提供多種形式時選定單一主要名稱，其餘存 aliases_zh_tw。Paladin 採聖騎士，Ranger 採巡林漢；Goblin(s) 族名與個體都用哥布林（使用者 2026-10-25 決定，取代指南的惡鬼族），Gray／Green Goblins 為灰哥布林、綠哥布林，俗稱 Gobs 為哥布仔。
同英文在指南中作組織與地點時分列，依 category 判斷；Seers of the Moonstone 經使用者決定，兩者都用「月之石預言者」。

## 對話

NPC 對話使用「」與『』；句尾標點置於引號之內。

不要把所有 NPC 硬翻成古文，也不要過度現代口語或加入網路用語。
依人物背景保留粗獷、正式、謹慎、傲慢等語氣差異；不額外創作情節與人物動機。
句子自然且資訊完整；省略主詞須仍能清楚辨識說話者與指涉。
原文刻意含糊、不可靠敘述、暗示或笑話須保留；不能為清楚而提前揭露答案。

## UI

短、一致、明確，採台灣常用詞。同一動作用語固定；字數限制由實際呈現驗證，不能靠刪除意義硬塞。
目前 bitmap UI 的技術限制與英文 fallback 不在本任務處理；此規範不是開始 HD UI 翻譯的授權。

## 物品、武器與護甲

一般命名順序：必要的狀態／材質／魔法修飾＋品類；同類裝備用同一核准品類詞。
專有物品名稱優先遵循正式來源，不為套用順序破壞專名。屬性順序或歧義需個別決策。
不將英文冠詞、複數與程式語法逐字變成中文名稱；未來必須配合 object-name／grammar 的技術規則。
武器／護甲品類、材質、穿戴部位與品質各自一致，不混成看似新物品的名稱。

## 法術與符文

法術顯示名稱以核准短名為主，效果說明另處理；同一作用或級別的命名模式一致。
符文名稱、符文含義、法術名稱與玩家必須輸入的 mantra／token 分開核對。
被程式比較的輸入 token 不因顯示翻譯而改寫。明示動態模板、控制碼與語法必須完整保留。
遇到手冊法術與遊戲實際效果不一致，列為 review-needed 並登錄 DECISIONS.md，不擅改語意或 gameplay。

## 審核界線

所有本輪 OCR 候選須先核對原圖與英文身份。文體規範可以是工作提案，不能用來覆寫 approved 術語。
本稿不直接匯入 master，不新增大量 target，也不宣告已完成遊戲全文翻譯。

## 詞表使用

以 GLOSSARY.tsv 的 term_id、category 和 canonical_zh_tw 為一致選詞來源。
TW_MANUAL_OCR_PROVISIONAL 表示本機手冊雙語辨識與獨立語意候選相符，仍非原圖人工核准。
review-needed 保留手冊差異待核；原始 OCR 差異與圖像不隨此稿發布。
符文／祈禱語保留輸入碼；禁止以全文尋找取代套用詞表。
