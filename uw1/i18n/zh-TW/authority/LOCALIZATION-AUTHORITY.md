# 來源與採詞規則

## 來源優先順序

1. 台灣正式發行版本隨附的中文手冊與正式中文資料。
2. 遊戲原始英文語意，以及合法遊戲資料與程式證明的用途。
3. 經確認的其他台灣正式 Ultima 中文出版物。
4. 經確認、長期高度一致的台灣玩家慣用譯名。
5. 本專案人工核准譯名。
6. 專案／Agent 暫擬譯名。

正式來源優先，不代表 OCR 一定正確。需核對原圖字形、英文身份、角色／物品用途與前後一致性。
公開來源的用途及限制見 [PUBLIC-REFERENCES.tsv](PUBLIC-REFERENCES.tsv)；單篇攻略與其他 Ultima 作品新聞不等於 UW1 官方定名。

## 選詞狀態

`GLOSSARY.tsv` 為主詞表。`project-selected` 是依使用者委託建立的一致選詞稿；`review-needed` 表示仍有手冊辨識或英文身份疑點。
兩者均非官方或人工核准。`TW_MANUAL_OCR_PROVISIONAL` 只在本機明示英文標籤與獨立可接受語意候選相符時暫採，仍需核對原圖。
`PROJECT_COMPOSITION_WITH_MANUAL_ROOT` 表示複合詞根沿用手冊候選，不能推論整個名稱在手冊中出現過。

明確手冊定名確認後優先沿用；疑似錯字、前後不一致或與遊戲用途衝突時保留異名與決策，不靜默改寫來源。
原始手冊辨識差異、座標與圖像仍在本機工作區；公開詞表保存來源 ID、掃描頁位及待核狀態。

## 同形異義與輸入碼

同英文但不同角色或用途分開識別。技能名稱與物件名稱可不同；角色自稱與冒犯稱呼也不能任意合併。
詞形搜尋只提供出處線索，不取代上下文判讀。先辨識完整專名，再處理一般詞；禁止用全域取代套用詞表。

符文、祈禱語與其他被程式比較的輸入碼保留原字母。中文含義、顯示名與輸入碼分開處理。
法術名稱、狀態效果與附魔分開；資料表列有名稱不代表玩家能施放該法術。
物件內部的陷阱／觸發器名稱是術語記錄，不表示新增玩家功能。

## 新詞與修訂

新增詞須記錄英文身份、分類、中文候選、遊戲出處與來源依據。語意確實未解的外語詞可保留原文，不為完成率硬造翻譯。
人工核准流程：核對原圖與英文身份 → 查重與查衝突 → 在 DECISIONS.md 記錄理由與核准依據 → 更新 status。
已 `approved` 的詞不得因 Agent 文風偏好自行更換；修改必須經提案、決策紀錄及人工審閱，保留舊詞與變更原因。

UW1／UW2 通用詞可列共享候選；不同作品同字但不同物件、法術或人物，必須先核對，不能自動沿用。

## 發布範圍

使用者於 2026-10-23 明確要求將權威檔上傳。本次發布權威選詞、分類檢視、來源註記與規則。
手冊二進位、完整或原始 OCR、手冊辨識差異原稿、完整英文遊戲文本、私人路徑與本機執行紀錄不納入 Git。
正式 master.tsv、runtime、遊戲邏輯與 catalog 不因本稿發布而改動。
