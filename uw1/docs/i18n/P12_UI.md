# P12 — 點陣 UI 與寫死的英文，接上 HD UI

**結果：PASS（Gate 見文末）。** 中文模式下，遊戲用點陣字或圖片畫的英文都改成 HD 中文，底下不留英文。
F11 設定畫面中文化，並新增「語言與文字」分頁。拆分堆疊物品改成滑桿與按鈕。英文模式與存檔不受影響。

## 做法

### HD 標籤層（M1 的基礎）

Exhume `runtime/port/presentation/hd_label.{c,h}`、`hd_label_draw.c`：

- **攔截點陣字：** `string_to_screen`（`gfx/grcore.c`）在 HD 中文下，有譯文的字串改成發布 HD 標籤，不畫點陣字。
  譯文來源依序為 `get_name` 剛寫的名稱、剛解出的字串（含被轉成大寫的）、程式寫死的片語（`phrases.c`）、
  移植版自己組的整句（`port_ui_next`）。數字與沒有譯文的字照原版畫。
- **何時消失：** 標籤記下底下背景的指紋。畫面上那塊背景改變，就不再畫。小的標籤另外存下原始像素，
  比對時跳過遊戲自己的游標（它畫在 HD 游標底下），所以游標經過時字不會消失。
- **雙頁緩衝：** 標籤記得自己畫在哪一頁（VIDMODE 的 Ytab）：
  - 不透明的圖（`show`）或實心矩形，只移除同一頁的標籤；
  - 透明圖（選中外框）保留標籤，並重新記指紋；
  - 從另一頁複製一塊過來時（矩形的畫筆模式），那頁的標籤跟著複製；
  - 游標的存檔與還原不動標籤。
- **覆蓋標籤：** 圖片裡本來就畫好的英文，先用底色蓋住，再寫中文。底色取框內不偏暗的顏色中最常見的，
  字色取框內最亮的常見顏色。
- **對齊：** 預設靠左；遊戲置中或靠右的地方，遊戲原始碼先呼叫 `hd_label_align`（包在 `#ifndef __TURBOC__` 裡）。

Exhume `runtime/port/presentation/qty_dialog.{c,h}`：「Move how many?」改成 HD 面板，內容是提示、滑桿、數值，
以及 −／＋／一半／全部／確定／取消。原版的輸入框照樣收答案：玩家在面板上的操作，由畫面層換成按鍵

### F11 設定畫面

- exhume（`runtime/port/ui/settings.{c,h}`）新增遊戲提供譯文與字型的掛鉤、設定列的說明與預覽欄位、
  `settings_set_start`，以及「語言與文字」分頁。這個分頁只在遊戲的設定表有它的列時才出現，其他遊戲不受影響。
  exhume 的 `settings_test.c` 新增 4 項檢查。
- UW1（`settab.c`、`i18n/settings_words.c`、`presentation/settings_text.c`；後兩者 2026-10-31 移入 Exhume runtime，與 UW2 共用）：中文模式下整個設定畫面用 HD 字型
  顯示中文，強化功能的名稱與說明也是。「語言與文字」分頁有：
  - 語言：English／繁體中文；
  - 中文字型：只列找得到的字型；
  - 字級、行距、黑框、反鋸齒：附預覽句。

  這些設定都寫進玩家設定檔，用的是 HD 文字讀取的鍵名，重新啟動後生效。
- **語言的決定方式：** 命令列有 `--locale` 時以命令列為準（測試與重播都會帶）。沒帶時讀設定檔的 `language`；
  設定檔也沒有、而且 `i18n/zh-TW/catalog.uw1loc` 存在，第一次啟動就用中文，並寫回設定檔。
  語言設定不寫進存檔，同一個存檔兩種語言都能讀。
- 設定檔選的字型在這個資料夾裡找不到時，改用預設字型，不中止啟動。
- 測試版的 `開始遊戲.bat`（`make_play.py`）不再帶 `--locale`，改由設定畫面決定語言。

### 玩家的中文文字（2026-10-24 使用者決定併入 P12）

Exhume `runtime/port/i18n/user_text.{c,h}`、`runtime/port/presentation/text_entry.{c,h}`：

- **輸入：** 角色名字與存檔說明，在中文模式下改由 HD 輸入面板輸入，支援輸入法。架構和數量對話框相同：原版的
  輸入框照樣收答案。按 Enter 時，面板把結果打進原版輸入框（存檔說明先 Ctrl+A、Ctrl+K 清空）。內容是 ASCII 就照打；
  含中文時打入 ASCII 替代值（名字「Avatar」、說明「Save 1」～「Save 4」），中文另存。
- **存放：** 存檔欄位只放 ASCII，UTF-8 不進原版 VM，存檔與原版相容。中文存成旁註檔 `SAVE0\NAME.UTF`、
  `SAVE0\DESC.UTF`；原版存檔時會把 SAVE0 整個複製到 SAVEn，讀檔時再複製回來，旁註檔就跟著走。
  沒有中文時不產生旁註檔，舊的會刪掉。重播不會輸入中文，所以不會產生旁註檔，存檔比對照舊。
- **顯示：**
  - 狀態面板、對話標題、結局畫面、角色建立、主選單的存檔清單：中英文模式都顯示中文。英文模式只在有中文名字
    或說明時才開啟標籤層，只處理這兩種字，其他照原版。
  - 遊戲內的存檔清單（訊息捲軸）與對話中的 `@GS8`：中文模式顯示中文；英文模式的捲軸是原版點陣字，顯示替代值。
- **存檔欄位名稱：** 選項選單的 I～IV 改為「存檔一」～「存檔四」，清單前綴「I- 」改為「存檔一：」。
- **測試用：** 輸入法無法用腳本模擬。測試環境（`EXHUME_TEST_CHEATS=1`）下設定 `UW1_TEST_TYPED`，
  面板打開時會預先填入該段文字。
