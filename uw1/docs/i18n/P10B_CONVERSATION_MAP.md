## 程式讀取稽核（BABL）

以 `babl_audit.py` 逐段反組譯對話腳本，追蹤每個字串 ID 到使用它的指令或內建函式：

| 用途 | 筆數 | 處理 |
| --- | ---: | --- |
| display（SAY、選單、print、say、respond、sex） | 4622 | 依類別翻譯 |
| compare（compare、contains、find、STRCMP） | 65 | **不翻。** 腳本拿它和玩家打字的答案或其他字串比對，翻譯後永遠比對不到；列入 `i18n/input-keys.tsv`，分類為 `input-token` |
| compose（append、copy、length、val） | 0 | — |
| none（沒有找到直接使用者） | 502 | 不參與比對，照常翻譯（可能經由變數間接顯示，或未使用） |

- 比對字串分布在 12 段對話：囚犯（slot 24，22 筆）、Rawstag、強盜頭子、Lakshi Longtooth、Garamon、蜥蜴人通用對話（slot 281）等。
  翻譯這些對話時，提示玩家輸入的句子要保留英文關鍵字，玩家才知道要打什麼（例如字謎或蜥蜴人的詞彙）。
- 若比對的是副程式參數，字串 ID 不會在比對點出現，稽核會漏掉；工具會偵測並回報這種寫法，出貨的腳本沒有。
- 稽核是線性掃描，不追蹤分支；它只用來找出不能翻的字串，「顯示」的判定不影響翻譯與否。
