最新功能來源 `6b00da4`，Exhume `5e92215`；整合包 `MANIFEST.json` 記錄組裝時的完整來源提交與每個檔案的 SHA-256。

## 內容

- P0～P12 中文化、HD 字型與游標、中文輸入、中文姓名／存檔說明／地圖註記。
- 傷害數字、敵人血條與攻擊觸發、以個體 HP 為血條上限；血瓶／法力瓶數值與增減數字。
- 自動開鎖、E 撿起、中鍵滑鼠視角、C 戰鬥／X 關容器、Z 開關地圖。
- 滾輪捲動袋子、翻過「繼續」及屬性頁技能列；技能滾輪已由使用者確認 OK，錄影漏記已修正。
- 全地圖、無敵與安全位置救援、無敵預開啟載入修正、自然明暗增亮及 0～15 強度、物件不損耗。
- 中文模式屬性頁英文／數字、英數或中英混合地圖註解使用 HD 字型。
- 空白鍵依使用者決定保留攻擊，跳躍維持 Shift／j；未重新綁定。

首次啟動由 catalog 自動選中文；F11 可切語言，啟動器不固定 locale 或開發機資料路徑。
遊玩強化與密技仍預設關，需玩家自行選擇。Mac 舊包本次未更新。
