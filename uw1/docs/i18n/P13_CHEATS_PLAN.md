# P13.7 密技選單規劃（2026-10-26）

狀態：需求整理與原始碼調查；尚未實作密技選單、全地圖或無敵，測試版執行檔沒有變動。

## 已確定的需求

- **全地圖**（2026-10-25）：只在畫地圖時顯示未探索區域，不修改探索紀錄與存檔。
- **無敵**（2026-10-26）：使用者要求「不扣血、不死」。不得以保留 1 HP 或死後補滿代替不扣血；
  不得因攔截死亡而留下無效座標、無限下墜、無法結束的物理迴圈或遊戲卡住。
- 密技選單由 F11 存取；分頁、其餘項目與操作細節尚未定案。原有強化功能規則適用：可開關，中英文都能使用。

## 其餘候選功能（尚未定案）

傳送到各樓層、指定位置或主要 NPC；取得常用物品；調整屬性與技能；補滿生命與法力；提高亮度；時間停止。
先前建議首版以全地圖、提高亮度、補滿生命／法力、樓層傳送為主；新加的無敵也是確定需求，實作順序另依設計安排。

## 無底洞與死亡流程調查

目前查到的玩法資料有深坑、熔岩與終局虛空，沒有足夠證據能斷言存在會讓角色永遠下墜的無底洞。
也沒有逐格驗證所有地圖，因此不能把「尚未找到」寫成「已證明不存在」。一般墜落由有限的地面／物件高度處理：

- `src/motion/MOTION.C`：`set_targz` 選擇地面或物件的落腳高度，`do_zbounce` 處理落地、停止與反彈。
- `src/motion/PHYSICS.C`：`phys_affect_player` 將撞擊轉為摔傷。`EtherealVoidSpecialEffects_seg008_150`
  則直接減少玩家 HP，不經過一般傷害入口；這本身不代表存在無限下墜。
- `src/critter/AI.C`：`damage_critter` 扣血並在歸零後呼叫死亡流程。只攔此處不足以符合不扣血需求。
- `src/combat/SPELLS.C` 的 `backfire` 會直接扣血；`src/conv/CONVVARS.C` 也會從對話變數回寫玩家 HP。
  實作時須分辨真實傷害與載入／初始化／最大生命調整，避免以一個全域回寫把合法狀態更動覆蓋掉。
- `src/game/UWEDIT.C`：`new_player_pos` 在跨層後仍找不到落腳點時直接設 HP = 0 並返回失敗。
  單純忽略這次死亡會讓玩家留在不完整的位置狀態，必須改走可恢復的失敗流程。
- `src/motion/PLAYMOVE.C`：`finish_player` 持續跑物理直到靜止。異常處理必須能在物理迴圈內生效，
  不能只依賴每次畫面更新時的檢查，也不能把任意長時間在空中一律判成異常。

玩法參考：[Ultima Codex 的 UW1 攻略](https://wiki.ultimacodex.com/wiki/Ultima_Underworld_walkthrough)
（火焰深坑、熔岩與終局逃離區域；有劇情內容）。技術判斷以本專案原始碼為主。

## 無敵的必要防護與驗收範圍

以下是待實作、待驗證的設計要求，不表示目前已有防護：

1. 攔截玩家受到的傷害與致死入口，涵蓋近戰、遠程、魔法、反噬、陷阱、中毒、飢餓、溺水、熔岩、摔落和虛空效果；
   一併稽核直接修改 HP 的分支。不得以每幀補血掩蓋扣血與死亡副作用。
2. 保留正常碰撞、落地、樓層切換、傳送、事件與結局；正常的長距離墜落、飛行或浮空不得誤觸救援。
3. 在讀取地圖格之前檢查座標與樓層，追蹤經驗證、可站立的安全位置；越界、無效落點或異常物理狀態時，
   停止異常移動並恢復到經驗證的安全位置，同步清理速度、加速度與待處理傳送狀態。
4. 傳送失敗須能回復可玩的完整位置狀態，包含已切換樓層的情況；不能只把 HP 從 0 改成正值。
   恢復前重新驗證落腳點，不得假定曾經安全的格子現在仍未被物件佔用。
5. 提供「返回安全位置」的救援操作，處理有地板但走不出去的深坑。安全位置尚未建立時，要有明確、經驗證的替代流程，
   不得盲目傳送或進入無限重試。
6. 驗證一般傷害完全不減 HP、直接扣血分支、深坑／熔岩／虛空、越界與無效傳送，以及開關無敵、存讀檔、
   正常換層與結局；關閉時維持原版行為。原生 sanitizer 與重播存檔相容性檢查也須通過。
