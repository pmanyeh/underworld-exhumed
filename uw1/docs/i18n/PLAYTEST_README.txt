Ultima Underworld 繁體中文整合測試版 @VERSION@（Windows x64）
==========================================================

使用你自己擁有的 GOG 版 Ultima Underworld 1。此包不含原版遊戲、玩家存檔或開發工具鏈。
這是開發中的私人測試包，譯文尚待人工審閱；catalog 含英文原文，請勿上傳公開網站。

開始遊戲
--------
1. 完整解壓縮後，雙擊「開始遊戲.bat」。
2. 程式會尋找 GOG 安裝位置；找不到時，請選擇你自己的 UW1 遊戲資料夾，或含 game.gog 的 GOG 安裝資料夾。
   也可以在本包旁放一個 UW 資料夾，內含你的 UW.EXE 及 DATA 等完整遊戲資料。
3. 第一次會先顯示設定畫面，按 Esc 進入遊戲。之後可隨時按 F11 開啟設定。
4. 存檔、設定與自動錄影都存在本包的 home 資料夾。複製整包到其他電腦時，請連同 home 一起帶走。
   沿用舊存檔時，請先備份，再將舊 home 下的 SAVE0、SAVE1～SAVE4 等所有 SAVE 資料夾複製過來。
   NAME.UTF、DESC.UTF、NOTES.UTF 是中文名字、說明與地圖註記的一部分，必須一起保留。

本版整合內容
------------
- 對話、書本、卷軸、物品、介面標籤與過場字幕中文化；中文名字、存檔說明及地圖註記。
- 屬性頁的英文姓名、數值，以及英數／中英混合地圖註解，使用高解析字型。
- F11「強化功能」：戰鬥傷害數字、敵人血條、血瓶法力瓶數值、自動開鎖、E 鍵撿起、滑鼠滾輪等。
- 滾輪可捲動袋子、翻過「繼續」；停在屬性頁技能列或箭頭上，每格移動一列，首尾停止。
- F11「密技」：全地圖、無敵、提高亮度、增亮強度 0～15、物件不損耗、記住／返回安全位置。
  密技預設關閉；亮度與物件不損耗等設定各自獨立。
- 敵人攻擊玩家時也顯示血條，最大值以首次顯示時的個體生命力為基準。
- 修正預先開啟無敵時的讀檔閃退；滾輪事件可正確記入錄影重播。

常用操作（開啟「現代按鍵」時）
------------------------------
- C：拔出／收起武器；X：關閉容器。
- 空白鍵：沿用上次方式攻擊，按住可蓄力。保留原有綁定，沒有改成跳躍。
- Shift 或 j：跳躍；Ctrl+Shift 或大寫 J：另一種原版跳躍。
- E：使用游標下的目標；搭配「E 鍵撿起」時，可拿的物品直接放進背包。
- Z：開啟地圖；非編寫註記時，再按一次 Z 關閉。註記中 Enter 完成、Esc 取消。
- F：屬性頁；R：符文袋；再按一次回到背包。

F11「語言與文字」可切換中英文及調整字型。標示需要重新啟動的設定，變更後請重開遊戲。
新增遊玩強化功能預設關閉，由玩家自行開啟；本包沒有預先開啟密技。
祈禱語、符文、暗語等需要照原文輸入的內容保留英文。

回報問題時，請註明版本 @VERSION@、操作步驟、F11 已開啟的功能，以及使用哪一個存檔。
