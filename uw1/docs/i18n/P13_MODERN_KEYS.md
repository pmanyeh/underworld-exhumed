# 現代按鍵：空白鍵跳躍、X 衝突與長按修正（2026-10-27）

使用者於 2026-10-27 改決定：空白鍵綁跳躍，取消「沿用上次攻擊方式」；另回報 X 會向前移動，以及 C 長按造成戰鬥模式反覆切換。
本次修改沿用 F11「現代按鍵」開關，預設關閉，中英文皆適用；使用者已於 2026-10-27 實測確認 OK。

## 操作與原因

- 空白鍵改走與 `j` 相同的原版跳躍指令。不再記住或執行上次攻擊方式；滑鼠攻擊與 `.`／`;`／`p` 的刺擊、揮砍、敲擊及蓄力保留。
  Shift／j、Ctrl+Shift／大寫 J 既有跳躍保留；啟用符文快捷鍵時，Ctrl+Alt+空白鍵仍為施法。
- X 原本同時註冊「關閉容器」及現代移動表的「慢速前進」；後者在每幀輪詢按住狀態時生效，並非關閉容器把角色推走。
  移除現代移動表的 X，只保留關閉容器，不另外指定慢速前進替代鍵。W 前進、S 後退及其他移動操作保留。
- C 戰鬥、Z 地圖、R／F 面板、X 關容器、Q／E 互動、G／H 資訊、反引號視角及跳躍，改為每次按下只觸發一次。
  地圖中的 Z／C 也只觸發一次。放開再按才再次執行；移動、視角俯仰、背包捲動及攻擊蓄力仍支援按住。
  文字輸入走原有路徑，地圖註記的 Z、空格與連續輸入不受影響。

## 輸入與重播

- 原本 `MOUSE.C` 的按住陣列每 30 ticks 重複提供按鍵，因此 C 等開關會在長按時不停切換。
  現代單次操作改用既有 `KEY()` 錄影邊界內的真實按下事件，從按住陣列排除這些操作；不添加讀時鐘或另用平台按鍵狀態。
- 以 `KEY()` 後的 `key_on` 計數辨識首次按下；放開與重新按下即使在兩次輪詢之間，仍可正確辨識。
  現代按鍵開啟時，計數飽和於 255，防止長按超過一輪計數後誤認為新按下。關閉時維持原版計數行為。
- 未更動錄影格式、既有錄影、goldens 或 verifier。舊版 modern-keys 錄影中的 Space／X 意義已隨本次使用者決定改變，
  不宣稱舊現代按鍵情境仍保有相同行為，也不自動覆寫其基準；一般原版模式回歸另行驗證。
- 既有私人 `test-state` 情境指令追加輸出拔武器、面板與開袋狀態，只供驗證，不改遊戲操作。
