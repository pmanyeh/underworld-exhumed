# P13.7 第 5 項：地圖中文註記（2026-10-25）

已完成，使用者已於 2026-10-25 實測確認地圖中文註記功能 OK。這是 P12 中文輸入功能的延伸，沿用語言與 HD 文字設定，沒有新增獨立強化開關。

## 操作

- 中文 HD 模式開地圖，點要寫字的位置，輸入中文或中英混合文字；Enter 完成，Esc 取消，Backspace 刪除最後一字。
- 編寫時 Z 是輸入文字；完成或取消後，啟用「現代按鍵」時再按 Z 才會關閉地圖。Esc 仍可關閉地圖。
- 用原有橡皮擦刪除註記；修改內容沿用原版的刪除後重寫。
- 每層最多 100 則；單則最多 46 字，靠近右邊時依可用空間縮短。中文字視需要縮小到可讀範圍。
- 正常存檔、讀檔即可保留註記。英文模式也會顯示存檔中已有的中文，英文模式新增註記維持原版輸入方式。

## 資料與相容性

- 原版 `struct ATM`、LEV.ARK 格式不變。有中文的註記只放四字元 ASCII 編號（例如 `#001`），UTF-8 存在
  `SAVE0\NOTES.UTF`。旁註檔使用版本標頭，依編號、樓層與座標對應，避免把其他 ASCII 文字誤當成中文。
- 選編號時避開現有中文與看起來像編號的 ASCII 註記；原版壓縮已刪除註記後，對應仍有效。
- 正常存讀檔會連同旁註檔複製。手動搬移存檔時請搬整個 SAVE 資料夾。DOS 或缺少旁註檔時顯示 ASCII 編號。
- 純英文註記不建立旁註檔。刪除只清理當層失效的對應，不會移除其他樓層的中文。
- 寫旁註檔先寫 `NOTES.NEW`，以 `NOTES.OLD` 備份舊檔，替換失敗則恢復舊檔；載入時可讀回中斷留下的備份。
  無效標頭不載入，壞列、重複編號、無效 UTF-8 與超限資料忽略。
- 原版刪除最後一則時不覆寫舊註記區塊，可能讓舊文字再次出現。刪除最後一則中文時，寫入一筆原版可理解的已刪除
  ATM 記錄（x = -1），避免零長度區塊與其他區塊共用位址。純英文重播維持原路徑。

## 呈現與執行緒

- `src/ui/AUTOMAP.C` 只加原生版 ASCII 掛鉤；DOS 分支保留。原版程式碼維持純 ASCII。
- 文字存在獨立的 100 則地圖快照，避免共用 HD 標籤的 64 則上限與重疊淘汰。全部點陣註記畫完後再更新底圖簽章。
- 橡皮擦的命中範圍與中心點使用實際中文字寬，能點到超出 ASCII 編號寬度的中文字。
- 遊戲執行緒排字，呈現執行緒只讀鎖定後的快照，使用自己的字型實例。離開地圖與換層清除快照，F11 設定蓋在上方。
- 英文模式原版羽毛筆游標也發布實際範圍；文字的底圖比對排除游標，避免寬羽毛筆使整則註記消失。

## 驗證

- `test_map_notes.py --sanitize`：146 項檢查通過 ASan／UBSan，涵蓋編號碰撞、樓層與座標、UTF-8 驗證、
  存讀、刪除與寫入失敗恢復、100 則重疊註記、長度與右側邊界、Z 輸入、取消和空白輸入。已加入三個原生平台 CI。
- 實際遊戲測試只使用 `build/i18n/map-cn/` 下可拋棄的獨立 home，沒有讀寫使用者測試版的存檔：
  同層兩則中文與另一層一則，遊戲內正式存檔後新程序讀回；中英文顯示；點中文字右端刪除、壓縮後保留其他註記；
  Esc 取消；刪除最後一則後反覆重開不復活；缺少旁註檔時安全退回 ASCII 編號。

  英文、中文 HD 與既有 DOS golden 一致。原版源碼 ASCII 檢查與 repocheck 通過。
