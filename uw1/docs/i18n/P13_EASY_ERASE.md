# 地圖橡皮擦輔助：強化功能 `easy-erase`（2026-10-29）

## 起因

使用者回報：地圖的 ERASE 橡皮擦「似乎失效」，點在要清除的註記上，卻變成輸入框。

以除錯版重播使用者的錄影（`home/recordings/20261029-133010`，在暫存複本上進行），印出每一下點擊的座標：

- 中文註記「測試標記」記在 x=193、y=100；可點中的範圍是 y 95～100（往上算）。
- 拿橡皮擦點的四下是 y=102、103、105、102，都比範圍高了 2～5 像素，判定為沒點中。
- 之後一下點在 y=95，被當成寫新註記，開出輸入框。

原因是原版本來的規則，不是移植或中文化造成的：

- 所有游標的熱點都在圖示正中央（`ui/MOUSE.C`：`hotspot_x = curs_w / 2 - 1`、`hotspot_y = cur_h / 2`），移植版畫的位置與原版一致。
- 橡皮擦要點在註記自己的框內（小字型的高度，6 個遊戲像素），框是英文或中文寬度都一樣。
- 沒點中時沒有任何提示：橡皮擦直接放下，游標變回羽毛筆，下一下點擊就開始寫新註記。

一般人會用橡皮擦的下緣去碰字，所以剛好落在框的上方。

## 使用者決定

選方案 3，做成預設關閉的強化功能 `easy-erase`（中文名稱「地圖橡皮擦輔助」）。開啟後：

- 點在註記附近也算點中：上方 6 像素、下方 3 像素、左右各 3 像素內。有多則時，依原版規則選中心較近的那則。
- 沒點中時保留橡皮擦，可以再點一次。
- 按右鍵、按 Esc，或在右側面板上沒點中（例如再點一次 ERASE 圖示），都會放下橡皮擦，地圖不會關閉。

關閉時完全是原版行為。

## 實作

- `ui/AUTOMAP.C`：新增移植版專用（`#ifndef __TURBOC__`）的 `port_erase_pick`，取代原版等待點擊的迴圈，只在開啟時使用。
  - 點中時，把點擊位置換成該則註記框內的一點（中心）。
  - 後面原版的擦除程式碼完全不動，包括選擇、標記已擦除和存檔。
  - 放下時給一個不在任何註記上的點。
  - 已擦除的註記（`x == -1`）不列入判定。
- 登記：`portgame.h` 的 `ENH_EASY_ERASE`、`sys/enhtab.c`、`i18n/settings_words.c`（名稱與說明），以及 `docs/ENHANCEMENTS.md`。
- `ui/key_help.c`：開啟時，按鍵說明的滑鼠段落多一行「右鍵、Esc　放下地圖的橡皮擦」。

## 驗證

- 在使用者存檔的暫存複本上，以使用者的強化設定、`mouse=follow`、中文 HD 字型 7 測試（截圖確認）：
  - 開啟時，點在字的上方會擦掉。
  - 關閉時，同一點沒擦到，維持原版。
  - 沒點中時游標仍是橡皮擦，再點就擦掉。
  - 右鍵、Esc、再點 ERASE 都會放下，游標變回羽毛筆，註記保留。
- 錄影回歸（英文）：先寫一則 AB，點 ERASE，點空白處落空，點 HELLO 上方 5 像素，存檔。
  - 關閉時存檔仍有 HELLO，開啟時 HELLO 被擦掉。
  - 兩者都是錄影→重播的檢查點與存檔雜湊完全一致。
  - 只剩一則註記時，原版擦掉最後一則不寫回存檔（`port_map_notes_save` 的註解），所以測試另外寫了一則 AB。
- F11 強化功能頁與按鍵說明頁截圖：新項目顯示正常。
- Windows 建置、`git diff --check`、repocheck（4,102 個檔案）通過，`AUTOMAP.C` 仍是純 ASCII。
