Ultima Underworld 1＋2 繁體中文版 @VERSION@（Windows x64，公開測試版）
=====================================================================

使用你自己擁有的 GOG 版 Ultima Underworld 1＋2。本包不含原版遊戲檔案。
這是公開測試版：遊戲很長，我們還沒有全部玩完，歡迎回報問題（見最後一節）。

開始遊戲
--------
1. 完整解壓縮後，雙擊 Underworld.exe，會出現選擇遊戲的畫面。
2. 點一下 Ultima Underworld 或 Ultima Underworld II 的圖片開始（或用 ← → 選擇、Enter 開始）。
3. 啟動頁會自動尋找 GOG 的安裝位置。找到時會顯示遊戲的標題畫面與位置；
   找不到時，開始遊戲後會請你選擇遊戲資料夾（含 UW.EXE／UW2.EXE 的資料夾，或含 game.gog 的 GOG 安裝資料夾），
   選過之後會記住。
4. 第一次啟動時會先顯示設定畫面，按 Esc 進入遊戲；之後隨時可以按 F11 打開。
5. Windows 可能顯示「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。

存檔與設定
----------
- UW1 的存檔與設定在 UW1 資料夾，UW2 的在 UW2 資料夾。搬到別台電腦時請連同這兩個資料夾一起帶走。
- 改版時：解壓新版後，把舊版的 UW1、UW2 資料夾裡的 SAVE 開頭資料夾與 .cfg 設定檔複製過去即可
  （i18n 資料夾請用新版的）。NAME.UTF、DESC.UTF、NOTES.UTF 是中文名字、存檔說明與地圖註記，請一起保留。

中文與強化功能
--------------
- 對話、書本、卷軸、物品、介面與過場字幕都已中文化；F11「語言與文字」可切換中英文、調整字型。
- F11「強化功能」與「密技」裡有許多選用功能（例如戰鬥傷害數字、敵人血條、拆分數量預設全部、全地圖），
  全部預設關閉，照原版遊戲開始；想用再自己打開。Shift＋F1 列出目前有效的按鍵。
- 祈禱語、符文、暗語等需要照原文輸入的內容保留英文。

回報問題
--------
啟動頁的「回報問題」按鈕會打開問題回報網頁。回報時請附上：
- 是 UW1 還是 UW2、版本 @VERSION@；
- 發生了什麼、怎麼操作的，最好附上截圖；
- 翻譯問題請直接引用畫面上的那句話；
- 遊戲當掉或卡住時，附上該遊戲資料夾裡 recordings 的最新一個檔案（自動錄下的操作紀錄，可用來重現問題）。

字型與程式授權見 licenses 資料夾；本包的檔案校驗與來源版本見 MANIFEST.json。
