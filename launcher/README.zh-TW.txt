地下創世紀 繁體中文版 @VERSION@（Ultima Underworld 1＋2，Windows／macOS）
=====================================================================

使用你自己擁有的 GOG 版 Ultima Underworld 1＋2。本包不含原版遊戲檔案。
兩款遊戲都很長，我們還沒有把每條路線都玩過；遇到問題或譯文不順，歡迎回報（見「回報問題」）。

其他說明檔：
- 說明_設定畫面.txt：設定畫面每個頁籤與項目的說明。
- 說明_MT-32音樂.txt：用 Roland MT-32 音源播放音樂的方法。

本說明中的「F11」是 Windows 的按鍵；Mac 打開設定畫面請按 Cmd+,（Cmd 加逗號）。


開始遊戲
--------
1. 完整解壓縮後：
   - Windows：雙擊 Underworld.exe。
   - Mac：雙擊「開始遊戲.command」（請保留資料夾裡的所有檔案，不要只把 Underworld.app 拖到「應用程式」）。
     本程式沒有經過 Apple 公證，第一次開啟會被擋下：請到「系統設定」→「隱私權與安全性」，
     在下方找到被阻擋的項目，按「仍要打開」，之後就不會再問。Apple Silicon 與 Intel Mac 都能執行，需要 macOS 11 以上。
   接著會出現選擇遊戲的畫面。
2. 點一下「地下創世紀：冥河深淵」（UW1）或「地下創世紀 II：萬界迷宮」（UW2）的圖片開始，
   或用 ← → 選擇、Enter 開始。玩的時候啟動頁會隱藏，遊戲結束後再出現。
3. 啟動頁會自動尋找 GOG 的安裝位置。找到時會顯示遊戲的標題畫面；
   找不到時，開始遊戲後會請你選擇遊戲資料夾（含 UW.EXE／UW2.EXE 的資料夾，或含 game.gog 的 GOG 安裝資料夾），
   選過之後會記住。若找到的是 GOG 的光碟映像（game.gog），第一次會把遊戲檔複製到 UW1、UW2 資料夾，只做一次。
4. 第一次啟動時會先顯示設定畫面，按 Esc 關閉並開始遊戲；之後隨時可以按 F11 打開。
   不想每次都先看到設定畫面，可在「遊戲」頁關閉「啟動時顯示本畫面」。
5. Windows 可能顯示「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。
   Mac 上 GOG 的遊戲是一個 app（例如「Ultima Underworld 1+2.app」），找不到時選擇那個 app 即可。
6. 本程式不會修改你的 GOG 遊戲資料夾。


中文化
------
- 對話、書本、卷軸、物品、介面、過場字幕與設定畫面都已中文化。
- F11「語言與文字」頁可以切換中英文、更換字型、調整字級與行距；存檔在兩種語言下都能讀。
- 人名、地名第一次出現時會加註英文原名，方便對照攻略（可在同一頁調整或關閉）。
- 祈禱語、符文、暗語等需要照原文輸入的內容保留英文。對話時要打字詢問的話題，打中文或英文都可以。
- 角色名字、存檔說明、地圖註記都可以用中文輸入（使用系統的中文輸入法）。


強化功能與密技
--------------
- F11「強化功能」頁有許多選用的新功能，例如現代按鍵（WASD）、滑鼠視角、血瓶法力瓶數值、
  戰鬥傷害數字、敵人血條、自動開鎖、拆分數量預設全部等。
- F11「密技」頁有全地圖、無敵、提高亮度、物件不損耗，以及卡住時的「返回安全位置」。
- 這些功能全部預設關閉，照原版遊戲開始；想用再自己打開。各項說明見「說明_設定畫面.txt」。
- 開啟「現代按鍵」後的常用操作：
  WASD 移動，方向鍵轉向與抬頭低頭；空白鍵跳躍；C 拔出／收起武器；
  Q 查看、E 使用（開啟「E 鍵撿起」時，可拿的物品直接放進背包）；
  Z 地圖（再按一次關閉）；R 符文袋、F 屬性頁；X 關閉容器。
- 任何時候按 Shift+F1，可以看到目前有效的所有按鍵。


存檔與設定
----------
- UW1 的存檔與設定在 UW1 資料夾，UW2 的在 UW2 資料夾。搬到別台電腦時請連同這兩個資料夾一起帶走。
- 改版時：解壓新版後，把舊版 UW1、UW2 資料夾裡 SAVE 開頭的資料夾與 .cfg 設定檔複製到新版的同名資料夾
  （i18n 資料夾請用新版的）。NAME.UTF、DESC.UTF、NOTES.UTF 是中文名字、存檔說明與地圖註記，請一起保留。
- 想沿用 GOG 原版（DOSBox）的存檔：把 GOG 遊戲資料夾裡的 SAVE1～SAVE4 複製到 UW1 或 UW2 資料夾。


音樂
----
- 預設使用 Sound Blaster 的音樂與音效。
- 有 Roland MT-32 或 CM-32L 的 ROM 檔，可以聽到當年最好聽的 MT-32 版本音樂，見「說明_MT-32音樂.txt」。


回報問題
--------
啟動頁的「回報問題」按鈕會打開問題回報網頁。回報時請附上：
- 是 UW1 還是 UW2、版本 @VERSION@；
- 發生了什麼、怎麼操作的，最好附上截圖；
- 翻譯問題請直接引用畫面上的那句話；
- F11 裡開了哪些強化功能與密技；
- 遊戲當掉或卡住時，附上該遊戲資料夾裡 recordings 的最新一個檔案
  （自動錄下的操作紀錄，可用來重現問題；在 F11「遊戲」頁的「錄製遊玩過程」開啟時才會有）。
